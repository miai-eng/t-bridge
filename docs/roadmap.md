# Roadmap

## Phase 1: Foundation
- Project setup (Next.js, Supabase)
- Data model: facilities, classrooms, children, staff, roles
- Authentication and role-based access with row-level security
- Fictional seed data

## Phase 2: Bilingual handover logs
- Create, view, and filter handover entries
- Translation with the original always displayed
- Entry history and handover status per child

## Phase 3: Staffing-ratio checks
- Encode age-based ratio standards as configurable rules
- Real-time check per classroom
- Warnings when a classroom falls below the standard

## Phase 4: Intercultural training
- Needs questionnaire
- Training plan generation from questionnaire results
- Stereotype review checklist and staff feedback

## Phase 5: Polish
- Mobile-friendly UI for use on the classroom floor
- Accessibility and bilingual UI
